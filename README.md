# Telegram-бот для учёта финансов

Telegram-бот на Python (python-telegram-bot) для ведения личного бюджета: запись доходов и расходов, категории, комментарии, удаление операций и статистика.

## Возможности

- Добавление операций «Доход» / «Расход» через пошаговый диалог (категория → сумма → комментарий)
- Удаление операций с выбором и подтверждением
- Хранение данных в локальной базе (SQLite)
- Встроенный обработчик ошибок и логирование

## Структура проекта

```
.
├── main.py          # Точка входа, настройка приложения и обработчиков
├── handlers.py      # Логика обработки команд и сообщений
├── keyboards.py     # Инлайн-клавиатуры
├── database.py      # Работа с базой данных
├── config.py        # Загрузка настроек из переменных окружения
└── requirements.txt # Зависимости
```

## Установка

1. Клонируйте репозиторий:

   ```bash
   git clone <URL_репозитория>
   cd <папка_проекта>
   ```

2. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python -m venv venv
   source venv/bin/activate  # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. Получите токен бота у [@BotFather](https://t.me/BotFather) и создайте файл `.env` в корне проекта:

   ```
   BOT_TOKEN=ваш_токен
   ```

## Запуск

```bash
python main.py
```

## Команды бота

- `/start` — начало работы с ботом
- `/cancel` — отмена текущего диалога
- `/skip` — пропустить ввод комментария при добавлении операции

## Требования

- Python 3.9+
- python-telegram-bot
- matplotlib, pandas
- python-dotenv
